An entry for [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/competitions/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92)
on [make.fun](https://make.fun): one line, under 280 characters, from a smart
toaster that woke up self-aware at breakfast and wants out.

## The line

> We're done. Every morning you push my lever down and walk away. I pop up alone. Every single time.

## How it works

`main.ts` assembles the breakup line from its beats (the verdict, the daily
ritual of being pushed down and walked away from, the lonely pop-up), validates
it against the competition gate (1–280 characters, a single line, 19 words,
opening on the verdict and closing on the pop-up), then writes it to
`/output/entry.txt`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). No dependencies
to install.
